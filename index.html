Seating assistant

Paste the guest list and any requests. Claude seats everyone at the tables on this plan, keeping each party together. If that can’t be done without conflicts, it can suggest a different table setup. Nothing changes until you press Apply.

Open this planner on claude.ai to use the seating assistant.

Tag any guest in square brackets after their name, like Jane Smith [salad, wine], or after a party’s name to tag everyone in it. Short forms work: “wine” means wine pairing. Click a tag to add it to the line you’re on.

Put allergies in the same brackets, like Ann Lee [soup, peanut allergy]. “Nut allergy”, “gluten-free” and “allergic to kiwi” all work; an allergy not on the list is kept as written. Click one to add it to the line you’re on.
